```bash

git clone https://github.com/lycheetah/cascade-framework.git
cd cascade-framework

# Install dependencies
pip install -r requirements.txt

# Run verification suite
python -m cascade.verify
```

### Basic Usage

```python
from cascade import CascadeSystem, CascadePresets

# Option 1: Use preset configuration
config = CascadePresets.balanced()

# Option 2: Interactive customization
from cascade import InteractiveCascadeCustomizer
customizer = InteractiveCascadeCustomizer()
customizer.start()
config = customizer.config

# Instantiate and run
system = CascadeSystem(config)
system.run()
```
